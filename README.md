# Escala 5x2 – Queen Plaza (AMVS Facilities)

Site estático com a proposta de escala 5x2 (EC 141/2026) para a equipe do Condomínio Queen Plaza: comparativo de 3 opções, calendário semana a semana de 14/12/2026 a 30/05/2027 e mapa de horas por pessoa.

- `index.html`: o site, um arquivo único. Abra no navegador ou publique em qualquer hospedagem estática.
- `src/`: template, calendários de cada opção (`opcao1/2/3.json`) e `build.py`, que regenera o `index.html` (`python3 src/build.py`).

Opção recomendada: 2 (plantão de fim de semana de 8h). Confirme com contador, jurídico e a convenção coletiva (SIEMACO) antes de aplicar.
